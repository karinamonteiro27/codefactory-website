# CodeFactory Solutions - Website Institucional

## 1. Descrição do Projeto
Website institucional da empresa CodeFactory Solutions desenvolvido para demonstrar a aplicação da Cultura DevOps e Integração Contínua.

## 2. Objetivo
Padronizar o fluxo de trabalho de desenvolvimento, automatizar testes/builds e containerizar a aplicação web.

## 3. Tecnologias Utilizadas
- HTML5 / CSS3
- Docker (Nginx)
- Git & GitHub
- GitHub Actions (CI)
